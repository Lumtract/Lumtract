# 导航与流转约束（N-系列）· 研究产出证据登记

### v10.2.0 · 依 ADR-0002 行动 #8 落盘

**诚实声明（缺口披露）**：N-系列的原始研究由研究代理（2026-09-15 并行两路）完成，其会话级笔记未随文件系统落盘——本文件是**从约束库与来源索引回溯整理的证据登记**，而非原始笔记全文。复审任何反直觉数字时，以本表「证据强度」栏为准，并回查文献原文。

**证据强度分级**（与卷二判定纪律一致）：
- **理论/实证共识**：多源、同行评审或教科书级支持 → 可支撑钻石
- **单项实验**：单篇研究、样本有限 → 可支撑钻石陈述但不可外推阈值
- **行业实证**：NN/g 等咨询机构量化研究 → 可支撑 [ENG] 佐证，不构成学术共识
- **平台行为**：官方 API/HIG 硬行为 → 必须带版本锚点（§2.6 快照）
- **假说（证据有限）**：原文自陈待检验 → 只可作 [ENG]，不得作钻石
