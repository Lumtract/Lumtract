---

## 1. 上下文 (Context)

Lumtract 产品层自发光（辉光）语义此前无体系约束，仅凭约定。外部一致性审查收敛定案（2026-09-15）§3② 指出两条缺位：

1. **辉光表达持久属性（重要度）** → 持续制造预测误差。锚：C-002 显著性退级（[PHYS] 钻石）——"大脑对已处理/已访问信息自动降低注意力分配。保持高显著性增加预测误差。"
2. **辉光改变元素格位**（撑开布局、引起位移）→ 破坏空间编码。锚：P-022 空间记忆（[PHYS] 钻石）——"空间记忆容量远超工作记忆。但依赖严格网格对齐。非网格布局破坏空间编码。"

两条锚均为钻石，且边界清晰互不重叠：C-002 管"显著性是否该退级"（时间维度），P-022 管"格位是否可变"（空间维度）。

---

## 2. 决策 (Decision)

在卷二 §2.3 内容逻辑约束新增 **L-004 辉光语义**：

| 字段 | 值 |
| --- | --- |
| **陈述** | 自发光（辉光）只表达瞬时状态，不得表达持久属性（重要度）；且不得改变元素占据的格位。 |
| **硬度** | 内容逻辑（派生自 C-002 显著性退级 + P-022 空间记忆，均为 [PHYS] 钻石） |
| **边界声明** | 瞬时状态 + 格位恒定 |
| **对设计的必然要求** | 辉光只用于瞬时状态（当前 / 激活 / 有更新等时间切片内意图，对齐 L-003 状态互斥）；禁止用辉光强度表达持久重要度——持续高显著性 = 持续制造预测误差（C-002）；辉光不得撑开布局、不得引起位移——非网格位移破坏空间编码（P-022）；响应式断点切换时格位可整体迁移，但不得在同一切口内渐变（对齐 N-017）。 |

与 L-003 的边界：L-003 管"交互状态（默认/悬停/按下/聚焦）的瞬时意图与状态互斥"；L-004 管"辉光这一视觉变量的语义边界（瞬时性 + 格位不变）"。两者相邻不重叠：L-003 是状态层的互斥裁决，L-004 是辉光层的语义边界。

---

## 3. 后果 (Consequences)

### 3.1 正面后果
1. 自发光语义首次进卷二：产品层辉光约定获得体系锚（钻石派生），不再是自创立法。
2. 基线清单 §4.5（发光语义约束）由"生态级自定义"改为**引用 L-004**——"三种状态：当前 / 激活 / 有更新"作为 [ENG] 应用层值保留在基线，卷四边界与产品应用解耦。

### 3.2 负面后果与成本
1. 卷二 +1 条约束（23 + 1 = 24 条体系约束），校验器 knownIds 自动纳入 L-004（无需改正则）。
2. 版本链同步：约束库 v10.4.0 → v10.5.0、archive 绑定、whitepaper 版本表、README ALIGN。

### 3.3 风险

| 风险 | 缓解措施 |
| --- | --- |
| 辉光语义被误用为"禁止一切辉光" | L-004 只禁持久属性表达与格位变化；瞬时状态（当前/激活/有更新）合法 |
| 与 L-003 状态互斥混淆 | 边界段明文区分（见 §2） |
| 产品层把"三种状态"当卷二内容 | 卷二只立边界，不输出设计值；三种状态属 [ENG] 应用层（基线 §4.5） |
