> 本 ADR 只做一件事：ADR-0004 §2.1 #3 平台固化规则的推翻路径。不碰外部惯例地位（N-017 已答）、不碰固化规则本身（ADR-0004 已立）、不碰实质槽位（等目的三问）。

---

## 1. 上下文 (Context)

ADR-0004 §2.1 #3 立平台固化机制：项目声明平台 P 时，§2.6 平台行为快照项将相关陶土约束固化为项目级硬边界（如小程序页面栈 10 层 → N-001 深度上限为硬边界）。

但逐词核验 ADR-0004 全文：`推翻` 0 处 · `目的` 0 处 · `解除` 0 处 · `例外` 0 处 · `复审` 0 处（仓库原始字节 grep 实证）。**固化规则立了，但没说能否被目的推翻——公理四（目的决定一切）在固化面前悬空。** 真冲突在这里：目的与固化硬边界相撞时，走什么通道，由谁裁决，如何记录，成本如何度量——全部是真空。

该冲突不在惯例层（违反外部惯例 = 一次性代价，N-017 已答），也不在固化规则本身（0004 已立）。补推翻路径不修改这两者。

---

## 2. 决策 (Decision)

1. **目的可推翻项目级硬边界**（服从公理四）。平台固化产生的硬边界，经目的三问 + 人类所有者裁决后，可被推翻。
2. **裁决权**：人类所有者（phyt-DNA：DNA 层归人类；争议升级也到人类所有者）。
3. **记录格式**：对固化边界的推翻与陶土调整走同一格式，扩展为 `[ENG: 调整为X，原因: Y，迁移成本: Z]`——X = 固化项，Y = 目的原因，Z = 迁移成本。
4. **Z 的量纲（硬约束，防操纵）**：受影响用户路径数 × 频次。**禁止无量纲数值**——无量纲可被双向操纵，审计不可复算。这是防"用不可复算的理由推翻硬边界"的关键闸门。
5. **复查入口**：十一审必查全部推翻记录（含 Z 是否合规、裁决是否经过人类所有者）；争议升级 → 人类所有者。

**不做什么 (Non-Goals)**：不修改 ADR-0004 固化规则本身；不裁决外部惯例地位（N-017 已答）；不预设实质槽位与生态契约条文（等目的三问）；不降低固化边界的默认硬度（推翻是例外通道，不是常态）。

---

## 3. 后果 (Consequences)

### 3.1 正面后果
1. 公理四与固化的冲突从"真空"变"通道"——真冲突现在有裁决路径、记录格式、成本量纲和复查入口。
2. Z 量纲写死：任何推翻必须有可复算的迁移成本，杜绝"无量纲操纵"。

### 3.2 负面后果与成本
1. 人类所有者介入频率可能上升——由十一审复查兜底，且推翻属例外通道（需目的三问 + 裁决 + 记录）。
2. 记录格式扩展（增加迁移成本 Z）——derivation.md §3.2.2 同步更新。

### 3.3 风险

| 风险 | 缓解措施 |
| --- | --- |
| 推翻被滥用，固化形同虚设 | 目的三问 + 人类所有者裁决 + Z 量纲强制 + 十一审必查 |
| 无量纲理由混入记录 | Z 禁止无量纲；审计复算路径数 × 频次 |
| 与"校验器不硬断言 [ENG]"工具纪律混淆 | 推翻只作用于项目推导上下文，不修改约束库原硬度（延续 ADR-0004 §2.1 #3 边界） |
