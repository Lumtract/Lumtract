# ADR-0008：L-004 辉光语义约束适用域收窄（P-022 锚限网格对齐区域）

| 字段 | 值 |
| --- | --- |
| **状态** | 已接受 (Accepted) |
| **日期** | 2026-09-15 |
| **决策者** | 人类（项目所有者） |
| **方法论版本** | phyt-DNA v1.0 |
| **体系版本锚点** | 约束库 v10.5.0 → v10.6.0（L-004 适用域子句） |
| **相关** | ADR-0006（L-004 本体）、C-002（显著性退级）、P-022（空间记忆）、N-004（寻路辅助） |

> 本 ADR 只做一件事：收窄 L-004 第二条的适用域——**P-022 锚仅对网格对齐区域生效**；非网格区域（DAG 图谱自由布局）P-022 不生效，辉光可作地标锚定。独立小修订，不改变 L-004 主体锚与第一条（C-002）。

---

## 1. 上下文 (Context)

L-004 第二条（辉光不得改变元素占据的格位）锚 P-022。核验 P-022 原文：**"空间记忆容量远超工作记忆。但依赖严格网格对齐。高频访问界面利用空间记忆必须严格对齐。非网格布局破坏空间编码并增加认知负荷。"** —— P-022 的适用前提是**界面为网格布局**（存在稳定格位）。

而 Lumtract 含 DAG 图谱视图（力导向 / 自由布局），**无稳定格位**，不满足 P-022 前提：

1. **锚悬空（不是错，是无效引用）**：图谱视图下 L-004 第二条引用 P-022，但 P-022 在该场景不成立——机器可校验的"锚定一致"成立（ID 存在），推导语义却悬空。
2. **反向风险**：图谱中节点位置本就动态，辉光可能是唯一定位线索——机械执行"辉光不得变化"反而加剧 desert fog（N-004 要求纯网络结构必须提供寻路辅助；desert fog 为参考级证据，Jul & Furnas 1998 类比）。

---

## 2. 决策 (Decision)

1. **L-004 第二条适用域收窄为"网格对齐区域"**（高频访问界面、稳定格位）。陈述与锚不变，边界声明补适用域。
2. **非网格区域（如 DAG 图谱力导向视图）**：P-022 锚不生效，第二条不适用；辉光可作地标锚定（辅助寻路，对齐 N-004 寻路辅助要求）。
3. **张力登记（留给推导时裁决，本 ADR 不预判）**：图谱中辉光作地标锚定（可能表达常驻 / 可返回位置）与第一条 C-002（辉光只表达瞬时状态，不得表达持久属性）存在张力——推导引擎冲突裁决顺位处理。
4. **不阻塞电商推导**：商品列表为网格布局，第二条正常生效。

**不做什么 (Non-Goals)**：不修改 L-004 第一条与 C-002 锚；不修改 P-022 本体；不预判图谱辉光地标的最终裁决。

---

## 3. 后果 (Consequences)

1. L-004 锚从"全局声称"变为"域内有效"——消除锚悬空（体系反冒充纪律的自身执行）。
2. 图谱视图的辉光使用获得合法空间（地标锚定），并明确与 C-002 的张力归属推导裁决。
3. 约束库 v10.5.0 → v10.6.0；校验器 knownIds 不变（L-004 已登记），无规则变更。

### 风险

| 风险 | 缓解 |

| 图谱辉光地标滥用为持久重要度 | 张力登记 + 推导裁决 + 十一审 |
