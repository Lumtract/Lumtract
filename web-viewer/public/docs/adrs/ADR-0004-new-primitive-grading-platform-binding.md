## 1. 上下文 (Context)

### 1.1 问题：新原语成为钻石的空白许可证

ADR-0003 将硬度-来源一致性规则定为"硬度含钻石 → 来源须含 [派生自] 或 [新原语]"——但 ADR-0002 §2.3 的钻石门槛要求"生理 / 认知的**不可变边界** + **充分学术共识**"。只要挂一篇文献就满足「新原语」，冒充形态再次迁移：

| 阶段 | 冒充形态 | 校验器 |
| --- | --- | --- |
| v10.1.0 | 整条冒充钻石 | 拦不住 |
| v10.2.0 | 半句无锚 | 拦不住 |
| v10.3.0 | 新原语即钻石 | 仍拦不住 |

校验器只查标签存在，不查标签含金量。实证：

- **N-004**「层级主干优于网络」依据 McDonald & Stevenson 1996（单一实验）+ Conklin 1987（观点文章）——实证设计发现，非生理不可变边界，却标钻石。
- **N-001**「两级优于三级」正文自陈"Encarta 百科实验，非普适硬阈值"——自我标注非普适的实验发现，钻石（认知负载）声明过强。

### 1.2 版本纪律

本批修订含约束语义变更（N-001/N-004 降级、新原语分级、平台固化机制），按 semver 属 minor：约束库 **v10.3.0 → v10.4.0**，推导引擎 **v10.1.0 → v10.2.0**。旧版本保留为历史，不作废。

## 2. 决策 (Decision)

### 2.1 决策内容

**1. 新原语分两级（修订 ADR-0003 §2.1 #1）。**

| 标签 | 含义 | 可标硬度 |
| --- | --- | --- |
| `[新原语: 认知架构: 文献]` | 工作记忆、注意、记忆衰减、寻路、预测等**认知机制**类理论 | 钻石 |
| `[新原语: 实证发现: 文献]` | 某实验 / 研究显示 A 优于 B 的**设计发现**，非机制边界 | 陶土，或「钻石待验证」（本 ADR 暂不引入该中间态） |

校验器规则相应收紧：**硬度含钻石 → 来源必须含 `[派生自]` 或 `[新原语: 认知架构]`**；`[新原语: 实证发现]` 不得支撑钻石（判冒充，阻断）；任何未分级的 `[新原语: X]` 判格式违规（阻断）。

**2. N-001 / N-004 裁决。**

- **N-001 → 纯 [ENG] 陶土**。依据为菜单深度 / 广度实验（Kiger 1984；Larson & Czerwinski 1998），且正文自陈"Encarta 实验，非普适"——实证发现，不构成充分学术共识；原钻石（认知负载）声明撤回。保留边界声明与"压缩深度优先"的工程指引（[ENG]）。
- **N-004 → 纯 [ENG] 陶土**。依据为单一实验（McDonald & Stevenson 1996）+ 观点文章（Conklin 1987）——实证设计发现，非认知机制边界；原"均为实证 / 理论共识"表述同步降级为"实证发现"。迷失（disorientation）的机制锚见 N-003（认知架构），不因 N-004 降级而丢失。
- **N-003 / N-007 保留钻石**（认知架构：寻路理论 Lynch 1960 / Passini 1984；目标记忆衰减 Altmann & Trafton 2002）。**N-012 / N-018 经 [派生自 C-001] 保留**（不受新原语分级影响）。

**3. 平台固化机制（新增，修订约束库 §2.6 与推导引擎 §3.2.1）。**

§2.6 平台行为快照目前是知识，不是规则。补充规则：**声明了某平台的项目内，该平台的快照项将相关陶土约束固化为硬边界**——固化仅对该项目生效，不修改约束库原硬度。硬理由：对小程序项目，页面栈上限 10 层使 N-001「扁平优先」从"体验差"变成"功能失败"（`navigateTo` 超出即失败）——超限不是体验问题，是功能消失。

推导引擎激活流程新增第五类「平台固化」：项目声明平台 P → 激活 §2.6 中 P 的对应快照项 → 相关陶土约束在该项目内固化为不可妥协。

**与工具纪律的边界**：固化 ≠ 把 [ENG] 升为钻石。① 约束库硬度不变（仍标 [ENG]）；② 固化发生在**项目推导上下文**，由平台硬行为（功能失败）驱动，非审美 / 体验判断驱动；③ 文档级校验器（lumtract-verify）仍不硬断言 [ENG] 阈值——两条纪律并行不悖。

**4. 授权范围明示。** 本 ADR 与 ADR-0003 共同授权：① N-系列硬度与来源类型修订（含降级 / 补锚 / 新原语分级）；② §2.6 平台行为快照（建立、扩展、**固化机制**）；③ 校验器断言边界（推导完整性 + 硬度-来源一致性 + 新原语分级）；④ 推导引擎第四类（导航场景触发）+ 第五类（平台固化）。卷二其余系列（P/C/L/R/D）不在修订范围。

### 2.3 不做什么 (Non-Goals)

- 不引入「钻石待验证」中间态（用户审查给出选项，本 ADR 选择直接降陶土——系统状态机保持简单；待有 2+ 独立实验共识再升回钻石）。
- 不修改 philosophy.md 与 P/C/L/R/D 系列。
- 不因 N-001/N-004 降级而削弱工程指引——陶土约束仍是必然要求，只是不冒充生理边界。

## 3. 后果 (Consequences)

### 3.1 正面后果

1. 新原语含金量进入机器校验——「新原语即钻石」的空白许可证关闭；冒充形态三级演进（整条 → 半句无锚 → 新原语）被第四级规则封死。
2. 钻石收敛：23 条中钻石声明从 v10.3.0 的 20 条降到 **18 条**，剩余全部为「派生自既有生理约束」或「认知架构类新原语」。
3. 平台快照从知识变规则：小程序 10 层等平台硬行为可在项目内固化，最有价值的数据进入推导链。

### 3.2 负面后果与成本

1. 导航层级与广度维度（N-001/N-002）不再有钻石——诚实优先；层级深度的机制方向（工作记忆）仍由 P-020 承载，但具体数值属实证发现。
2. ADR 链继续变长（0000→0004）——符合"已接受 ADR 不可覆盖"纪律。
3. 平台固化机制依赖「项目平台声明」步骤（derivation §3.2.1 第五类），推导引擎需在执行时采集。

### 3.3 风险

| 风险 | 缓解措施 |
| --- | --- |
| 认知架构标签被滥用（观点文章冒充机制理论） | 分级规则 + ADR 审查逐条核验；research-notes 证据强度分级已登记 |
| 平台固化被误读为「把 [ENG] 升钻石」 | §2.1 #3 明确边界：固化仅项目内生效、不修改原硬度、由功能失败驱动 |
| N-001/N-004 降级后团队误以为层级设计不重要 | 陶土仍是必然要求；navigation.md §六 与推导引擎持续断言 |
