**键鼠端不可动的三条**：⌘/Ctrl+S 保存、⌘Z 撤销（跨平台最强记忆，违反即失败）；链接默认样式可点击；浏览器/系统返回键行为可预测（N-005 回溯，钻石锚）。

## 2. L2 品类级：文档站点（最强可抄区域）

### 2.1 三层导航分工

| 位置 | 装什么 | Lumtract 对应 |
| --- | --- | --- |
| 顶栏 | 主要分区 | 生态入口 + 一级分区 |
| 左侧栏 | 当前分区内嵌套页面 | 推导链结构树 |
| 页脚 | 项目与支持资源 | 仓库链接 |

### 2.2 逐条可抄项

- 面包屑：3 层以上层级必备；放页面顶部、全局导航下方；除当前页外全部可点；`>` 或 `/` 分隔（[ENG]）
- 上/下一页：每篇文档底部，构成引导式学习路径——philosophy → constraints → derivation 天然是有序推导链（[ENG]）
- 当前位置指示：导航区高亮当前项，滚动保持（锚 N-021）
- 可折叠分组：管理大分区复杂度（[ENG]）
- 搜索随规模升级为主要发现手段（[ENG]；锚 N-001 检索出路）
- 导航是可维护资产：结构定义在配置文件、走 PR review（[ENG]）
- 从文件结构自动生成导航：Lumtract 已有 dag-manifest.json，天然适配（[ENG]）

### 2.3 设计系统文档层

- 主导航限制条目数保证可扫性（N-002，[ENG] 陶土：顶级导航 ≤5，随机列表 4–8）
- 组件状态指示：experimental / stable / deprecated（L-003 状态互斥锚）
- 相关组件链接、See also、上/下一页——把文档从"可查"变成"可逛"
- 分组类别匹配用户心智模型，而非内部组织结构
- 顶层页面标配：Intro / Get started / Contribution / Design Tokens / Changelog

## 3. L2 品类级：知识图谱（抄一半、丢一半）

### 3.1 该抄的

| 做法 | 来源 | 说明 |
| --- | --- | --- |
| 反向链接放侧边面板，不是主视图 | Obsidian [ENG] | 正文仍是主舞台 |
| 图谱是用户主动召唤的独立视图 | Obsidian graph view [ENG] | 默认不在主界面 |
| 双链语法 `[[...]]` | Obsidian [ENG] | 已成事实标准 |
| 表格/列表作为图谱降级呈现 | 见 3.2 实证研究 | 图不可读时用户宁可要表格 |

### 3.2 明确不要抄的（有实证）

- **不要用节点-连线图做默认主视图**。证据：arXiv 2304.01311（面向知识图谱实践者的访谈研究，N=19）：12 位受访者明确指出节点-连线图（NLD）在上千节点规模下终端用户无法解读，9 位形容其变成"毛线球（hairball）"；有团队做出图形界面后，最终用户**宁可要一张表格**（"preferred a table"）。同一研究反复出现的主张：**越让终端用户远离底层图结构，他们越愿意接受结果**。（研究原文已独立核验，引用干净）
- **不要做无边界画布的默认视图**，除非同时配齐：常驻地标 + 一键回到全局。否则触发 desert fog——视野里无可定位线索时，用户行为不是耐心搜索，而是乱撞后退出。（**参考级**：desert fog 源自 Jul & Furnas 1998，原始语境为多尺度地图 / ZUI，外推到文档 + 图谱属**类比，非直接证据**；结论可用，证据强度须按此标注）

## 4. L3 生态级：Helix 家族契约（目的三问后定实质槽位）

### 4.1 槽位契约
一级入口编号固定（slot 1–5），跨应用不换位置。[ENG] 生态自定，一旦定下全线锁死。

### 4.2 地标契约
- 左上 = 生态身份与返回（永不移动）
- 右上 = 全局意图入口
- 全生态同构
- 锚：P-022 空间记忆 + N-017 位置即外置记忆

### 4.3 通道契约
⌘K / Esc / 撤销语义全生态统一；Esc 退出层级顺序一致（锚 N-005）。

### 4.4 自适应红线
- 智能层只允许**叠加**（复制预测项到附加区），不允许**移动**已有元素；必须提供锁定与回退。
- 依据：C-001（[PHYS] 钻石）派生——对**已形成使用经验的用户**，重排产生预测误差；新手无预测模型，重排无害甚至有益。**此 scope 必须保留**——缺它会把对新用户的引导式适配一并禁止。
- **不登记量级数值**（+18% / +25% 等原引自外部实验的无源数字已撤回）——规则保留，量级不作为断言。

### 4.5 发光语义约束（引用 L-004，卷二 v10.5.0）
自发光只表达**三种状态：当前 / 激活 / 有更新**，且位置恒定。[ENG] 应用层值。
**禁止**用辉光强度表达动态重要度——L-004（[PHYS] 钻石派生，C-002 显著性退级）：辉光只表达瞬时状态，持续高显著性 = 持续制造预测误差；且辉光不得改变元素占据的格位（P-022 空间记忆）。

## 5. 无障碍必过项（新增，N-020 ~ N-023）

生态级项目漏 A 级合规项不是优化项，是实打实的洞。以下四条为**必过项**（N-系列钻石/双标注）：

| 约束 | 合规项 | 要求 |
| --- | --- | --- |
| N-020 | WCAG 2.4.1 **A** | 跳过重复导航块（Skip to content） |
| N-021 | WCAG 2.4.3 **A** | 键盘焦点顺序符合阅读与操作逻辑（[PHYS] 钻石，P-021） |
| N-022 | WCAG 2.4.5 **AA** | 多种定位方式并存（站点地图 / 搜索 / 面包屑） |
| N-023 | WCAG 2.5.7 **AA** | 拖拽提供替代操作（[PHYS] 钻石，P-010 + P-011） |

## 6. 反惯例清单：这些"流行做法"不要抄

| 做法 | 为什么不要 |
| --- | --- |
| 汉堡菜单当**主**导航 | 隐藏导航劣于可见导航（N-009，[PHYS] 钻石可发现性：NN/g 179 人研究，可发现性下降近 50%）；只配做溢出容器 |
| 手势作为唯一入口 | 无可发现性线索，短暂访问用户不会发现（N-009 锚） |
| 用动画过渡揭示隐藏功能 | 实测无效——用户看到动画却未与产品联系（[ENG] 实证惯例） |
| 智能重排 / AI 个性化导航 | 破坏空间记忆与程序性记忆（见 4.4，C-001 scope 规则） |
| 品牌个性放在交互层 | 品牌活于视觉表达，不在可用性模式（[GENE] 皮肤层归属） |
| 极简到失去视觉锚点 | 剥离线索后用户失去"信息气味"参照，跳出率升高（P-022 锚） |

## 7. 上线前自检表

- [ ] 每个视图都能一瞥回答「我在哪 / 我能去哪」（N-021）
- [ ] 深层级提供并行检索路径（搜索 / 索引 / 站点地图）（N-001）——**不设"≤3 层"硬断言**
- [ ] 面包屑 + 上/下一页 + 当前项高亮 三者齐全
- [ ] ⌘K 覆盖搜索、跳转、动作三类
- [ ] Esc 退出层级语义统一且已文档化
- [ ] 断点降级只交换功能等价组件（P-022/N-017）
- [ ] 全图视图配齐常驻地标 + 一键回全局（desert fog 参考级）
- [ ] 个性化只叠加、不移动，且可锁定（C-001 scope）
- [ ] 发光仅用于三种恒定状态，不表达持久重要度（L-004）
- [ ] **N-020 ~ N-023 无障碍四条全部通过（WCAG 2.4.1 A / 2.4.3 A / 2.4.5 AA / 2.5.7 AA）**
- [ ] 导航结构定义在配置文件中，可走 PR review
